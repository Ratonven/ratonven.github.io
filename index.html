Lapisan Security

Cryptography Layer

Security is not a feature.
It is the foundation upon which every trustless interaction stands.

LAYER 01
⬡
Hashing
A one-way function that converts any data into a fixed-length output. SHA-256 produces 64 hexadecimal characters — changing one input bit creates a completely different output.
INPUT: "hello world"
SHA256 → b94d27b99...3ef4
LAYER 02
🔑
Digital Signature
A private key signs, a public key verifies. You can prove ownership without exposing the secret — this is the foundation of crypto wallets.
SIGN(msg, privKey) → signature
VERIFY(sig, pubKey) → true
LAYER 03
🛡
Multi-Layer Encryption
Elliptic Curve Cryptography (secp256k1) + AES-256 + Merkle Tree. Every layer adds complexity that exponentially increases the security of the whole system.
ECC → key pair
AES → data at rest
MERKLE → proof of inclusion

// Manifesto

Principles
that Survive

01
Decentralization = Freedom

When nobody controls the system, everyone becomes equal. Blockchain is not only technology — it is a statement that power should be distributed, not centralized. Every node is an equal voice.

02
Trustless = Evolution

We do not need to trust another entity — we trust mathematics. Smart contracts cannot lie. Code cannot be bribed. This is not about distrust; it is about moving beyond the need for trust.

03
Complexity = Strength

System paling tangguh lahir dari lapisan-lapisan yang saling mengunci. Kriptografi, konsensus, ekonomi token — bukan kelemahan karena rumit, melainkan kekuatan karena tidak bisa disederhanakan oleh musuh.
